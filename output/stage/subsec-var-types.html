    Subsection 5.1.2 Variable Types

    Take a look back at the chart in Example 5.1.3. There are six different variables. Each of these variables falls into one of two main types:
    • A categorical (qualitative) variable has possible values that can be categorized or described easily in words. The possible values of a categorical variable are called levels.
      🔗
      🔗
    • A numerical (quantitative) variable takes values that can be represented by a number, AND it makes sense to add, subtract, or average the values.
      🔗
      🔗
    Note that is also acceptable to use these terms to describe the data collected for each variable.
    🔗

    Example 5.1.5.

    Sort the six variables in the chart from Example 5.1.3 in categorical or numerical.
    🔗
    Hint.
    Be careful … one variable is a bit tricky. There are two numerical variables and four categorical variables.
    🔗
    🔗
    Solution.
    The two numerical variables: the number of morning classes and the GPA. The remaining variables are categorical. A student’s room number is the tricky one. The data is recorded with a number, BUT it doesn’t make sense to do any mathematics with those numbers. The number just serves as a label; in some buildings rooms are labeled with letters or a combo of letters and numbers.
    🔗
    🔗
    🔗
    We can further sort variables into subtypes. Numerical variables are either continuous or discrete. Continuous variables are those that come from measurement or computation and can have values that are not whole numbers. In our example, GPA is a continuous numerical variable. Discrete variables are those that result from counting and can only have whole number values. The number of morning classes is an example of a discrete numerical variable.
    🔗
    Categorical variables can be binary, ordinal, or nominal. The morning person variable is binary; there are only two options for an value: yes or no. When the possible values (levels) of a categorical variable where a particular order is clear, that is an ordinal variable. This could be the case if we allowed the students to choose one of
    • Very Much
      🔗
      🔗
    • Somewhat
      🔗
      🔗
    • Rarely
      🔗
      🔗
    • Not At All
      🔗
      🔗
    as responses to the question. In the example, the student’s room number is an ordinal variable. If a categorical variable has more than two possible values and those values don’t have a clear order, then that is a nominal variable. Both the student’s name and their major are nominal variables.
    🔗

    Observation 5.1.6.

    One distinction between continuous and discrete numerical variables is in the set of possible values the associated data could have, whole numbers only rather than all the possibilities in between. This can cause a mix-up of thinking any limit at all on the possible values must mean that the variable is discrete. For example, there is a reasonable range on possible heights for an adult human. The values of these data will be at least 1ft and not more than 10ft (that’s an extra safe interval). Height is still a continuous variable! It is almost always safer to ask, “Do we get this number by counting (discrete) or measuring (continuous)?”
