Example 4.2.2.

For the same scenario as Example 4.2.1,
  1. How tall will the tree be at the start of 2027?
    🔗
    🔗
  2. When will the tree be 42 feet tall?
    🔗
    🔗
🔗
Solution.
For (a), we are given (indirectly) a value for the input variable \(t\text{,}\) “the start of 2027.” We need to translate these words into a numerical value for \(t\text{.}\) How many years is January 2027 from July 2016? When \(t = 10\text{,}\) it is July 1, 2026, which we get by adding 10 to 2016. The start of 2027 is six months later, so we need to add a half of a year onto our value of \(t\text{.}\)
🔗
We substitute the value \(t = 10.5\) into our model formula:
\begin{align*} h \amp = 12 + 1.5t\\ \amp = 12 + (1.5)(10.5)\\ \amp = 12 + 15.75\\ \amp = 27.75 \end{align*}
So, in January 2027, the model predicts that the tree will be 27.75 feet tall.
🔗
For part (b), we are given a value, 42, for the output variable \(h\text{,}\) and need to findthe corresponding value of \(t\text{.}\) Less thinking is required to translate the words into quantities, but algebra will be required to solve the equation. The value \(h = 42\) is substituted into the formula and we use algebra to isolate the variable \(t\text{:}\)
\begin{align*} h \amp = 12 + 1.5t\\ 42 \amp = 12 + 1.5t\\ 42 - 12 \amp =12 + 1.5t - 12\\ 30 \amp = 1.5t\\ \frac{30}{1.5} \amp = \frac{1.5t}{1.5}\\ 20 \amp = t \end{align*}
🔗
Finding \(t = 20\) means 20 years after July 1, 2016. So, in July 2036, the tree will reach a height of 42 feet.
