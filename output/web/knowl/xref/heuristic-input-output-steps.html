Procedure 4.2.3. Solving Input or Output Problems.

Once you havea formula for the model, the process for answering a question about that model are always pretty much the same.
  1. Translate the words into a quantity for the appropriate variable using the definition of the variable.
    🔗
    🔗
  2. Substitute this value into the model formula.
    🔗
    🔗
  3. Determine the corresponding value of the other unknown variable.
    🔗
    🔗
  4. Translate that quantity back into a meanigful answer using the definition of the variable; don’t forget to include the units!

    🔗
